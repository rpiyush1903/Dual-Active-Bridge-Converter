# Dual-Active-Bridge-Converter
This repository contains the design, simulation, and hardware implementation of an isolated bidirectional Dual Active Bridge (DAB) DC-to-DC converter optimized for electric vehicle (EV) charging infrastructure. Addressing the efficiency limitations of conventional hard-switching converters, this project introduces a modified DAB topology featuring an LLC2 resonant network. By maintaining zero voltage across switches during transitions, the design achieves universal Zero Voltage Switching (ZVS) across all eight primary and secondary switches, significantly reducing switching losses and thermal stress. The system utilizes Single Phase Shift (SPS) modulation to simplify control while effectively managing bidirectional power flow.
